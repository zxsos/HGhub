## HGhubX 2.0.0

HGhubX 2.0 是一次完整的品牌、网络、播放和跨平台界面升级，保留旧版本本地数据与环境变量兼容能力。

### 更新点

- **品牌与迁移**：统一使用 HGhubX 名称；首次启动时迁移旧 HGhub/HGhubX 本地数据；继续兼容旧环境变量，并优先使用 `HGHUBX_*` 配置。
- **播放源与线路**：恢复发布页线路解析、自动选线和手动选线；线路切换、取消和重新加载使用会话保护；保存的线路可在重启后恢复。
- **镜像与代理**：新增自定义镜像；支持跟随系统代理、自定义代理和直连三种模式；应用代理覆盖请求与播放链路。
- **网络诊断**：区分 DNS、TCP、代理和 HTTP 传输问题；补充线路、目标地址、耗时和处理建议；复制报告时自动隐藏代理凭据。
- **界面**：更新了 UI。
- **iOS 图标**：使用全幅方形 HGhubX 图标源，由 iOS 系统负责圆角裁切；生成并校验全部 18 个 iPhone、iPad 和营销图标槽位；移除 IPA 中的 Tauri 默认图标。

### 修复点

- 修复 Linux WebKit 将本机媒体请求错误送入系统代理，导致接口可用但视频无法播放的问题。
- 修复重复 `Content-Length`、Linux 开发 CSP 和播放失败后的重试状态问题。
- 修复 iOS 生成工程仍使用 Tauri 默认图标的问题。
- 修复 Windows NSIS 构建中图标生成脚本嵌套启动 `pnpm.cmd` 导致 `spawnSync EINVAL` 的问题。

### 兼容性

- 旧版 HGhub/HGhubX 本地数据会在首次启动时迁移。
- 旧环境变量继续可用，新增配置优先使用 `HGHUBX_*` 命名。
- iOS 发布包为未签名 IPA，需要使用 Apple 账号签名后安装。

### 构建产物

- Linux amd64：`.deb`
- Android：arm64、arm、x86_64 分 ABI APK
- Windows：x64 安装包和便携版 ZIP
- macOS：Universal `.dmg`
- iOS：未签名 `.ipa`

### 验证

- Frontend checks、Rust checks 和发布工作流全部通过。
- Windows、macOS、Linux、Android、iOS 全平台构建成功。
- iOS 图标生成、18 个图标槽位、评分定位和移动端布局测试通过。
- `v2.0.0` 使用 SSH 签名 annotated tag，GitHub 验证通过。
